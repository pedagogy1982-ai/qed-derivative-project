01

프로젝트 개요

왜 미분계수를 몸으로 확인하려 하는가

교과서의 미분계수는 그래프 위의 기호로만 배우기 쉽습니다. 이 프로젝트는 실제로 달리고 굴러가는 물체를 촬영해 위치–시간 데이터를 얻고, 그 데이터에서 평균변화율과 순간변화율(미분계수)을 직접 계산해 두 개념의 차이를 눈으로 확인하는 것을 목표로 합니다.

평균변화율 (구간 [a, b]) \[ \dfrac{s(b) - s(a)}{b - a} \]
순간변화율 = 미분계수 (t = a) \[ \lim_{h \to 0} \dfrac{s(a+h) - s(a)}{h} = s'(a) \]

두 점 P, Q를 잇는 할선의 기울기가 평균변화율이고, Q를 P로 한없이 가까이 보낼 때 할선이 다가가는 접선의 기울기가 순간변화율(미분계수)입니다. 실험에서는 h를 완전히 0으로 만들 수 없으므로, 영상의 한 프레임 간격처럼 실제로 만들 수 있는 가장 작은 Δt로 근사합니다.

할선 (평균변화율, P–Q) 접선 (순간변화율, P에서)
02

지식 코너 · 회귀추세선

측정한 점들로부터 하나의 식을 얻는 방법

목적

구간별로 Δx/Δt를 계산하는 방식은 두 점 사이의 어림값일 뿐입니다. 측정한 (시간, 위치) 점들을 대표하는 하나의 식 s(t)를 구할 수 있다면, 그 식을 미분해서 어느 순간의 순간속도든 정확히 계산할 수 있습니다. 이때 데이터로부터 식을 얻는 방법이 회귀추세선입니다.

원리 — 최소제곱법

흩어진 데이터 점들과 예상 곡선 사이의 차이(오차, 잔차)를 구하고, 그 오차의 제곱합이 가장 작아지도록 곡선의 식을 결정하는 방법입니다. 스프레드시트·계산기의 "추세선 추가" 기능이 바로 이 원리로 동작합니다.

어떤 차수를 쓸까?

  • 실험 B(공 굴리기) — 등가속도 운동이라 2차식 s(t) = at² + bt + c 가 물리 법칙과 잘 맞습니다.
  • 실험 A(달리기) — 사람은 초반에 가속하다 속도가 일정해지므로 2차식이 완벽히 맞진 않지만, 전체 경향과 구간별 순간속도를 보는 데는 여전히 유용합니다.

미분과의 연결

회귀식이 s(t) = at² + bt + c 라면 \[ s'(t) = 2at + b \]

회귀식을 한 번 구하면 특정 순간 t를 대입해 그 순간의 순간속도(미분계수)를 바로 계산할 수 있습니다. 아래 실험 A·B의 데이터 표에는 입력하는 즉시 이 회귀식과 R², 미분한 속도 함수가 자동으로 계산되어 나타납니다.

측정한 데이터 점 회귀곡선(최소제곱법) 오차(잔차)

결정계수 R²

회귀식이 데이터를 얼마나 잘 설명하는지 나타내는 값으로 0~1 사이입니다. 1에 가까울수록 데이터가 회귀곡선 위에 정확히 놓인다는 뜻이고, 0에 가까우면 곡선이 데이터를 잘 설명하지 못한다는 뜻입니다.

04

실험 A · 50m 전력질주

달리는 학생의 순간속도를 미분계수로 확인
EXPERIMENT A

사람이 만드는 s(t) 그래프

목적

50m를 달리는 동안의 구간별 평균속도와, 특정 순간(예: 25m 통과 순간)의 순간속도(미분계수)를 비교하여 “속도”라는 말이 실제로는 특정 시점의 미분계수임을 확인한다.

준비물

  • 운동장 또는 직선 트랙 50m 구간
  • 거리 마커(라바콘 등) 11개 — 0, 5, 10, … 50m 지점
  • 줄자 (마커 간격 확인용)
  • 이미 촬영한 달리기 영상 (측면 고정 촬영본)
  • 영상분석 프로그램 — Tracker(무료) 또는 Kinovea, 또는 스마트폰 슬로우모션 재생
  • 노트북, 스프레드시트(엑셀 · 구글시트)
  • 보조 스톱워치 1개

진행 절차

  1. 영상을 분석 프로그램에 불러오고, 화면 속 5m 간격 마커 사이의 실제 거리로 축척(스케일)을 보정한다.
  2. 영상을 프레임 단위로 재생하며 달리는 학생이 각 마커(0~50m)를 통과하는 순간의 시각 t를 기록한다.
  3. 거리(x)–시각(t) 표를 완성하고, 구간별 Δx/Δt(평균속도)를 계산한다.
  4. 특정 지점(예: 25m) 주변에서는 프레임 1~2개 단위로 더 촘촘히 위치를 읽어, 아주 작은 Δt에서의 평균변화율로 그 순간의 순간속도(미분계수)를 근사한다.
  5. x–t 그래프를 그리고, 전체 구간의 할선과 25m 지점의 접선을 함께 표시해 두 값의 차이를 시각화한다.

데이터 기록 양식 실시간 계산 · 실시간 공유

4명이 각자 달린 기록을 탭으로 나눠 입력합니다. 시간 간격을 정하고, 그 시각까지 이동한 거리(위치)를 입력하면 구간 Δx·평균속도가 자동으로 계산됩니다.

주의 실제 전력질주 전 충분히 준비운동을 하고, 트랙 표면 상태(바닥 미끄럼, 장애물)를 미리 점검합니다. 마커는 발에 걸리지 않도록 트랙 바깥쪽에 낮게 배치합니다.
05

실험 B · 경사면 공 굴리기

등가속도 운동에서도 같은 방법이 통하는지 검증
EXPERIMENT B

공이 만드는 s(t) 그래프

목적

경사로를 굴러 내려가는 공은 사람과 달리 (거의) 등가속도 운동을 한다. 같은 방식으로 미분계수를 구했을 때, 순간속도가 시간에 따라 일정하게 커지는 것을 확인하여 실험 A의 방법이 다른 운동에도 똑같이 적용됨을 보인다.

준비물

  • 경사로 (긴 나무판 · 홈이 있는 레일 등, 각도 조절 가능하면 좋음)
  • 공 또는 구슬 (굴러가며 튀지 않는 것)
  • 눈금 테이프 또는 줄자 — 5~10cm 간격 위치 표시
  • 각도기 (경사각 측정 · 기록용)
  • 이미 촬영한 공 굴리기 영상 (경사면과 평행한 측면 고정 촬영본)
  • 영상분석 프로그램 (실험 A와 동일)

진행 절차

  1. 경사로 각도를 고정하고, 출발점부터 도착점까지 5~10cm 간격으로 눈금을 표시한다.
  2. 영상 속 눈금으로 축척을 보정한 뒤, 공이 각 눈금을 통과하는 시각을 프레임 단위로 기록한다.
  3. 거리–시각 표를 만들고 구간별 평균속도(Δx/Δt)를 계산한다.
  4. 출발 직후 구간과 도착 직전 구간 각각에서 순간속도(미분계수)를 근사해 두 값을 비교한다.
  5. x–t 그래프와, 속도가 시간에 비례해 커지는지 확인하는 v–t 그래프를 함께 그린다.

데이터 기록 양식 실시간 계산 · 실시간 공유

공 종류와 경사각이 다른 3번의 시도를 탭으로 나눠 기록합니다. 지점과 통과 시각을 입력하면 구간 Δx·Δt·평균속도가 자동으로 계산됩니다.
